# CDriveAnalyzer

Анализатор места на диске C: для Windows 11 x64, версия 1.2.

## Скачать и запустить

Скачайте [CDriveCleaner.exe](./CDriveCleaner.exe) через кнопку Download raw file и запустите.
При запуске выполняется только анализ. Программа показывает крупные файлы и папки,
включая AppData, Roaming и Local, и отмечает неполные результаты.
Двойной щелчок открывает расположение в Проводнике.

Отдельные вкладки позволяют очистить старые временные файлы и запустить
штатные деинсталляторы выбранных приложений после подтверждения.
Это не инструмент автоматического удаления всего содержимого C:.

## Ограничения

Размеры логические: вложенные строки нельзя складывать, жесткие ссылки могут
учитываться повторно. Ссылки и недоступные каталоги пропускаются.
EXE не подписан. Сборка и тесты правил прошли, но запуск GUI и операции
на настоящей Windows 11 не проверены. Деинсталляторы не изолированы от других дисков.
Подробности: [инструкция](README_RU.txt), [проверки](VALIDATION.txt).

## Сборка

Нужны Python 3 и Zig 0.14.1:

```sh
python build.py /path/to/zig
```

## Тесты правил (Linux, g++)

```sh
g++ -std=c++17 tests/policy_test.cpp -o policy_test
./policy_test
g++ -std=c++17 tests/scan_test.cpp -o scan_test
./scan_test
python tests/verify_binary.py CDriveCleaner.exe
```
